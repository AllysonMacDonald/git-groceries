# Meal plans — weekly history

The Monday planner appends each week's six dinners here (**newest at the top**)
so it can avoid repeating a recipe used in the last ~3–4 weeks. This is the
planner's memory — read it before picking, write to it after.

Format for each week:

```
## Week of YYYY-MM-DD
- Vegetarian: <title>, <title>
- Meat & veg: <title>, <title>
- Kid (8yo, no-heat): <title>
- Kid (12yo, stovetop): <title>
```
